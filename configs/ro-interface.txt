# L'interfaccia tra la parte di sola lettura gia' sui portatili e gli slot RW
# che una capsula ci scrive sopra (docs/vboot.md#limits).
#
# Una capsula non scrive mai WP_RO: gli slot di ogni release partono dopo il
# bootblock e il verstage della prima release con vboot (v1.3.0). Questi
# lasciano il loro stato nella cache-as-RAM per la romstage: il buffer di
# lavoro di vboot, la console prima della RAM, i timestamp, le cache di FMAP
# e CBFS. Gli slot devono trovarli agli stessi indirizzi e nello stesso
# formato, che arriva con il commit di coreboot.
#
# tools/ci-check.sh confronta la riga coreboot con il pin di tools/build.sh,
# tools/verify-rom.sh le regioni della cache-as-RAM con romstage e bootblock
# di una build. Si cambia solo con una release che riscrive anche la parte di
# sola lettura (flashrom), o dopo aver controllato che i nuovi slot leggono
# ancora quello che lascia la vecchia.
#
#   coreboot DESCRIBE           da cosa e' costruita la parte RO sui portatili
#   VARIANTE SIMBOLO INDIRIZZO  una regione della cache-as-RAM (car.ld), come la scrive nm
